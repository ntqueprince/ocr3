# SHIVANG — GitHub upload folder

इस folder की सभी files GitHub पर upload करने के लिए तैयार हैं। किसी build, npm install या backend की जरूरत नहीं है।

1. ZIP को Extract All करें और SHIVANG-GitHub-Upload folder खोलें।
2. इसके अंदर की सभी files अपनी website वाली GitHub repository के root में upload करें। index.html उसी जगह होना चाहिए जहाँ पहले था। ZIP file को website की जगह upload न करें।
3. पुराने समान नाम वाले app files को इन नए versions से replace करें और नई files भी साथ upload करें। .nojekyll भी रखें।
4. Commit करने और Pages update होने के बाद website खोलें। पुरानी copy दिखे तो Ctrl+Shift+R दबाएँ।

इस्तेमाल: Shivang Local OCR Plus चुना रहने दें → स्क्रीनशॉट Ctrl+V करें या फोटो/PDF चुनें → OCR पूरा होने दें → Download all PDF दबाएँ। सेव हुई PDF में RPH25 जैसे चुने हुए हिस्से को copy करें।

दोनों local OCR engines और PDF assets यहीं bundled हैं। OCR.Space · Online चुनने पर पुराना online विकल्प इस्तेमाल होता है।

यह deployment folder है। Synthetic tests, sample documents, browser profiles और development dependencies इसमें शामिल नहीं हैं।
